# Приёмка

Веб-система управления объектами ремонта под ключ для DOLGIY STUDIO (Воронеж).

Ядро системы — одно действие: прораб отмечает принятую позицию сметы, и тем же действием
начисляется сдельная оплата по ставке позиции, уменьшается остаток текущего транша,
позиция попадает в акт выполненных работ.

## Посмотреть

Демонстрация продукта работает без сервера: экраны настоящие, подменён только слой
доступа к сети, данные берутся из встроенного слепка стенда.

Сайт собирается на каждый push в `main` и в ветки `claude/**` работой
`.github/workflows/pages.yml`, но **развёртывается только с ветки по умолчанию**: окружение
`github-pages` выкладку с других веток запрещает, и работа развёртывания на ветке не
запускается вовсе. Адрес поэтому обновляется слиянием в `main`, и никак иначе. Метка коммита
в адресе (`…/?v=<коммит>`) отвечает на вопрос, какая именно итерация открыта.

## Жёсткие инженерные требования

- Деньги — целое число копеек. Тип `number` для денежных величин запрещён.
- Каждое начисление хранит снимок ставки на момент приёмки.
- Отмена — сторнирующая запись, не удаление. История не переписывается.
- Разграничение доступа на уровне полей, а не экранов.
- Все цвета, размеры и отступы — из токенов дизайн-системы.

## Как поднять стенд

```bash
cp .env.example .env      # задайте пароли
docker compose up --build # база, объектное хранилище, API с миграциями, веб-клиент
```

Веб-клиент — http://localhost:5173, API — http://localhost:3000.

Без Docker:

```bash
pnpm install
pnpm --filter @priyomka/api exec prisma generate
DATABASE_URL=… pnpm --filter @priyomka/api run migrate:deploy
DATABASE_URL=… node apps/api/prisma/seed.mjs   # обезличенный стенд
pnpm --filter @priyomka/api run build && pnpm --filter @priyomka/api run start
pnpm --filter @priyomka/web run dev
```

## Вход

Пароля нет. Руководитель входит по номеру телефона в два шага: номер, затем
шестизначный код. Прораб и заказчик не вводят ничего — им руководитель выдаёт
персональную ссылку; самостоятельной регистрации в продукте нет. Вне промышленной
среды код и ссылка показываются прямо в ответе: ни отправка сообщений, ни почтовый
отправитель на стенде не настроены.

## Приватность данных

Реальные сметы, фотографии объектов и данные клиентов в репозиторий не попадают.
Каталог `/private/` исключён из индексации. Фикстуры тестов обезличены.
