## 2. Функциональная карта сайта

Референс делит функции на три группы. Приводится дословная номенклатура — она же служит контрольным списком объёма.

### 2.1 Рабочие проекты

**Замер:** интерактивный обмерный план с автоматическим расчётом площадей · экспорт обмерника в PDF (инженерная версия).

**Смета:** площади в смету (автозаполнение из обмерника) · «самое быстрое осмечивание» через шаблоны и актуальные цены поставщиков · выгрузка PDF-сметы для клиента · **смета в график** — конвертация этапов сметы в периоды диаграммы Ганта.

**Работа:** диаграмма Ганта с контролем сроков и прогресса · видеонаблюдение за объектом · удалённый доступ клиента к видеопотоку · база инструментов · инвентаризация по QR-кодам.

**Отчёт:** бесконечные фотоотчёты с кабинетом клиента · генератор счетов и актов · удалённый доступ к отчётам вместо пересылки файлов · **контроль прогресса на основе закрытых актов** · чеки с привязкой к проектам.

### 2.2 Управление делами

**Персонал:** автоматизация зарплат с выплатами по графику · выплаты самозанятым с сохранением чеков.
**Клиенты:** собственная CRM с конвертацией заявки в клиента · формы для сайта (Tilda, Flexbe, Marquiz, API).
**Бухгалтерия:** жизнь документов · онлайн-подписание по ЭЦП через СМС · онлайн-касса по 54-ФЗ (интеграция Ferma).

### 2.3 Настройка системы

Конструктор документов с переменными (имя, счёт, адрес, телефон) · цифровая подпись · факсимиле подписи и печати · администрирование доступов · две системные роли (администратор и клиент) с настраиваемыми правами.

### 2.4 Интеграции

Банки: Тинькофф, Сбер, Альфа, Точка. Видеонаблюдение: Ivideon. Плюс карты, СМС-шлюзы, государственные сервисы проверки контрагентов, открытый API. Всего заявлено более двенадцати партнёров.

## 3. Интерфейс приложения (по скриншотам)

### 3.1 Глобальная навигация

Горизонтальная шапка на всю ширину, залитая фирменным индиго. Слева логотип, по центру — навигация в виде **пилюль**: Главная · Заявки · Проекты · Контрагенты · Бухгалтерия · Ещё ▾. Справа — блок пользователя пилюлей (имя, аватар) и колокол уведомлений. Активный пункт выделен белой заливкой пилюли.

Под шапкой — цветная подложка того же индиго с заголовком страницы и хлебными крошками. Ниже начинается белое рабочее полотно. Приём даёт заметную «шапку-обложку» без отдельного сайдбара.

Мобильная версия: нижняя таб-панель из пяти пунктов (Главная, Заявки, Проекты, Кон-ты, Ещё) с иконками и подписями.

### 3.2 Главная (дашборд руководителя)

Три карточки в ряд, каждая с заголовком капсом и двумя строками «значение + подпись»:

- **БАЛАНС** — 338 370,00 ₽ наличные · 1 522 910,25 ₽ банк
- **ЗАПЛАНИРОВАННЫЕ РАСХОДЫ** — 0,00 ₽ страховые взносы · 40 561,00 ₽ НДФЛ
- **БЮДЖЕТ** — 427 829,50 ₽ свободные средства · 763 870,00 ₽ запланированные поступления (со значком подсказки)

Далее — недельная лента: семь карточек-дней с числом и днём недели, переключатель «‹ Сегодня ›». В днях — либо серая отметка «Задач нет» с галочкой, либо цветные чипы событий: жёлтый «Сдача актов выполне…», бирюзовый «17:00 Заработная плата», красный «20:45 Связаться с кли…». Цвет чипа кодирует срочность.

Ниже — три группы счётчиков с крупными числами и иконками: **Заявки** (первичный контакт 7, знакомство 5, принимают решение 7, согласование договора 3), **Задачи** (к выполнению 1, просроченные 2), **Проекты** (в работе 25, новых 30).

Внизу — «● Прямой эфир»: горизонтальная лента превью с камер объектов, на каждом бейдж кода объекта (`R-19`, `R-23`, `R-30`, `R-31`) и кнопка воспроизведения.

### 3.3 Карточка объекта

Заголовок: бейдж кода `R-99` крупно, рядом адрес «Плесецкая Улица 1, с. 1, кв. 1». Под ним хлебные крошки Главная › Проекты › объект.

**Левая колонка (сводка):**
- «Баланс проекта» — 95 201,00 ₽ крупным начертанием, первым элементом страницы;
- статус «▶ В работе» в светло-голубой карточке с кнопкой «Изменить статус»;
- **карточка почтового шлюза**: «Чеки на материалы отправляйте на checks@stworka.com с темой `P-999`», где код объекта выделен красной пилюлей;
- индиго-карточка срока: «Осталось **30** дней», дедлайн 5 ноября, справа кольцевой индикатор 47 %;
- блок «ИНФОРМАЦИЯ»: клиент со ссылкой и кодом `[300] Иван Иванов`, реквизиты клиента (физ. лицо), наблюдатели (с действием «Изменить»), адрес со ссылкой на карту, ключи «2 комплекта», реквизиты исполнителя.

**Правая колонка (рабочая область):** горизонтальные табы Обзор · Подрядчики · Акты · Счета · Финансы · Документы · Ключи · Статистика, активный подчёркнут. Под табами — видеокарточка объекта, затем «График производства работ» с кнопкой «Изменить ›» и метриками в рамках: `235 / 327` (рабочих дней / календарных дней на работы), `363` (календарных дня по договору). Ниже — «Авансовые платежи на материалы» с пустым состоянием «Платежи отсутствуют».

### 3.4 Мобильный экран обмерника

Компактная шапка с кодом и адресом, кнопка «назад». Блок «Общее»: количество помещений, площадь, площадь стен, периметр потолка, периметр пола, объём — числовые значения выделены цветом. Кнопка «Скачать» с иконкой документа. Горизонтальные табы помещений (Спальня, Коридор, Санузел, Кухня, Гостиная, Ванная) со скроллом. Переключатель «Вид: Обычный / **Pro**». Далее — карточки групп («Основное», «Окна», «Двери») с парами «параметр: значение» и миниатюрой плана помещения справа.

## 6. Чего в референсе нет и что составляет наше отличие

1. **Связь «принятая позиция → начисление сдельной оплаты по ставке этой позиции».** У Stworka зарплата — самостоятельный модуль с выплатами по графику, у 101 — распределение вознаграждения, у Gectaro — акты из смет. Ставка оплаты труда как атрибут позиции сметы, срабатывающий в момент приёмки, не реализована ни у кого из трёх.
2. **Работа траншами 300–500 тыс. ₽.** Референс показывает «Баланс проекта» — остаток по объекту. Заказчику нужен остаток **по текущему траншу**: сколько ещё можно выработать до следующего акта и оплаты.
3. **Отчёт о расхождениях при импорте сметы.** Импорт как таковой у конкурентов есть или предполагается; проверка контрольных сумм с явным показом расхождения — нет.
4. **Порог входа для полевого пользователя.** Отзывы фиксируют высокий порог освоения у всех трёх продуктов, оценка мобильного приложения референса в RuStore — 3,7 из 5 при 5,0 в отзывных каталогах. Заказчик не смог завершить регистрацию в продукте-образце 101. Три касания до отметки приёмки — наше проверяемое требование, а не пожелание.

## 7. Ограничение по заимствованию

Копируются **структурные и взаимодействующие решения**: расположение блоков, состав карточки объекта, механика почтового шлюза, принцип сквозного кода. Не копируются: фирменные цвета, логотип, начертания, тексты интерфейса и маркетинговые формулировки референса. Скриншоты используются как аналитический материал и в поставку продукта не входят.

## 9. Сверка панелей, 03.09.2026

Основание: требование заказчика «панели должны совпадать и быть похожими по структуре». Сверены одиннадцать панелей референса против артбордов дизайн-канвы и работающего продукта. Решение по оформлению: раскладка, состав и порядок блоков — у референса, палитра, гарнитуры и иконки — наши (ограничение раздела 7 сохраняет силу).
