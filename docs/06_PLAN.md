Документ фиксирует полный состав работ и текущее состояние. Обозначения: **✔ сделано** · **◑ частично** · **○ не начато** · **⛔ заблокировано** (указано чем).

## Решения, действующие как ограничения

Двадцать два решения допроса. Ключевые, влияющие на код: деньги — целые копейки `bigint`, тип `number` для денег запрещён; начисление хранит снимок ставки; отмена — сторно, не удаление; разграничение на уровне полей, а не экранов; получатель начисления — бригада, наследуется от мастера этапа; остаток транша считается по клиентской сумме с надбавкой 12 %; приёмка пакетная, одно фото на пакет, порог трёх касаний относится к пакету; версионирование сметы гибридное; импорт жёстким парсером плюс эталонный шаблон; размещение на зарубежном хостинге до Э6.

## Демонстрация для просмотра

GitHub хранит исходники, но не запускает приложение, а репозиторий приватный. Продукт состоит из клиента, API на Fastify и базы PostgreSQL, поэтому статический хостинг показал бы форму входа, которая упрётся в отсутствующий сервер.

Решение: демонстрационная сборка **того же клиента** — экраны настоящие, подменяется только слой доступа к сети (`apps/web/src/api.demo.ts`). Слепок ответов снимается со стенда скриптом `scripts/capture-demo.mjs`, страница собирается `scripts/build-demo.mjs`, витрина дизайн-системы — `scripts/build-showcase.mjs`.
