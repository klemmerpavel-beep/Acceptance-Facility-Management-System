## Контекст

Документ фиксирует полный состав работ и текущее состояние. Обозначения: **✔ сделано** · **◑ частично** · **○ не начато** · **⛔ заблокировано** (указано чем).

Состояние на 05.09.2026: репозиторий `klemmerpavel-beep/acceptance-facility-management-system`, ветка `claude/f1-karkas-platformy`, 154 теста зелёных, шесть пакетов рабочего пространства проходят `tsc` в строгом режиме. Витрина дизайн-системы: `claude.ai/code/artifact/1a566c88-2ef4-4f02-9f57-09a25bce1b10`; витрина трёх экранов на приёмку — `design/crm.html`.

Источник правды по составу экранов и переходов — `docs/07_IA.md`, утверждён заказчиком 03.09.2026. Источник правды по объёму — `docs/01_PROJECT.md` редакции 1.2. Двадцать два решения допроса и утверждённые правки к нему — в разделе «Решения» ниже.

## Демонстрация для просмотра

GitHub хранит исходники, но не запускает приложение. Продукт состоит из клиента, API на Fastify и базы PostgreSQL, поэтому статический хостинг показал бы форму входа, которая упрётся в отсутствующий сервер.

Решение: демонстрационная сборка **того же клиента** — экраны настоящие, подменяется только слой доступа к сети (`apps/web/src/api.demo.ts`). Слепок ответов снимается со стенда скриптом `scripts/capture-demo.mjs`, страница собирается `scripts/build-demo.mjs`, витрина дизайн-системы — `scripts/build-showcase.mjs`.

Сборка даёт два файла: `design/demo.html` — самостоятельная страница, которую открывают файлом без сервера, и `design/demo.artifact.html` — тот же код без обёртки `html/head/body` для публикации. Так же устроена витрина дизайн-системы.

Витрина трёх экранов на приёмку собирается отдельно — `scripts/build-crm.mjs` из `design/crm.body.html`. В отличие от демонстрации она статична: показывает три экрана и три обязательных состояния для разметки замечаний, а не работает.

Три решения стадии, изменившие исходную постановку:

1. **Площадь стен идёт по периметру потолка, а не пола.** Проверено на числах артборда: 97,39 × 2,70 = 262,95 сходится, по периметру пола вышло бы 232,39 — недосчёт в тринадцать процентов оплачиваемой работы. Обе величины измеряются, ни одна не выводится из площади.
2. **Контур помещения не рисуется, план объекта загружается снимком.** Рисованный контур без редактора геометрии был бы правдоподобной картинкой вместо обмера. Хранилище файлов подключено портом с единственной реализацией на файловой системе; клиент S3 не вводится до переезда в облако (пункт 6.1).
3. ~~**Перенос площадей в количества позиций сметы отложен до C.2.**~~ Закрыто стадией C.2: лист правки позиции подставляет в количество площадь пола, площадь стен или один из двух периметров — те величины обмера, что подходят единице позиции. Какую из подходящих взять, решает человек.
