# Приём замечаний по демонстрации

Демонстрация уходит заказчику постоянной ссылкой, и замечания к ней до сих пор
возвращались письмами и голосовыми: «на третьем экране цифра непонятная» — без
экрана, без ширины окна, без даты. Виджет в правом нижнем углу принимает то же
замечание вместе с обстановкой, в которой оно возникло, и складывает всё в одну
таблицу.

Виджет живёт **только в демонстрационной сборке** (`main.demo.tsx`). В продукте
его нет: там замечание идёт прорабу и руководителю в работу, а не в таблицу
обзора.

## Что уходит в таблицу

| Столбец | Откуда берётся |
|---|---|
| Когда | время приёма на стороне приёмника |
| Вид | «Идея», «Дефект» или «Вопрос» — выбор в форме |
| Экран | подпись раздела, на котором стоял человек (`[aria-current="page"]`) |
| Объект | код объекта, если открыта карточка (`.stamp__value--code`) |
| Вкладка | выбранная вкладка карточки (`[role="tab"][aria-selected="true"]`) |
| Ширина | ширина окна в пикселях — отделяет дефект раскладки от дефекта данных |
| Имя | необязательное поле «Кто пишет» |
| Текст | само замечание, до 4000 знаков |

Обстановка снимается из разметки, а не передаётся состоянием: виджет стоит рядом
с продуктом, а не внутри него. Цена решения названа прямо — имена узлов
повторены вторым местом и разойдутся, если узлы переименовать. Взамен продукт не
несёт ни одного поля ради обзора, который закончится вместе с обзором.

## Устройство

Демонстрация раздаётся статикой с GitHub Pages и сервера не имеет. Поэтому
приёмник внешний: веб-приложение Apps Script, привязанное к Google-таблице.
Страница шлёт в него `POST` с телом JSON, скрипт дописывает строку.

Тип содержимого запроса — `text/plain` **намеренно**. С `application/json`
браузер шлёт предварительный запрос `OPTIONS`, а веб-приложение Apps Script на
него не отвечает, и отправка не доходит вовсе. Разбирает тело всё равно тот же
скрипт, и тип заголовка ему безразличен.

Адрес приёмника берётся из переменной сборки `VITE_FEEDBACK_URL`, а не из
исходного текста. Довод не в тайне: веб-приложение развёрнуто с доступом «Все» —
иначе страница без сервера не смогла бы в него писать, — и адрес, который обязан
знать каждый посетитель, тайной не является. Довод в том, что приёмник меняют
без правки продукта.

**Переменная не задана — виджета нет вовсе.** Кнопка, открывающая форму, которая
ничего не отправляет, хуже отсутствия кнопки: заказчик напишет замечание и будет
считать его переданным. Довод тот же, по которому продукт не показывает неработающего;
прежнее правило допуска из `07_IA.md` отменено заказчиком, но довод пережил правило.

## Настройка (делается один раз)

1. Открыть таблицу «Приёмка — замечания заказчика по демонстрации» на Диске.
2. Расширения → Apps Script. Вставить скрипт ниже вместо содержимого файла.
3. Развернуть → Новое развёртывание → тип «Веб-приложение»;
   «Запуск от имени» — от своего имени; «У кого есть доступ» — **Все**.
4. Скопировать адрес развёртывания вида
   `https://script.google.com/macros/s/…/exec`.
5. В репозитории: Settings → Secrets and variables → Actions → Variables →
   New repository variable, имя `FEEDBACK_URL`, значение — этот адрес.
6. Следующая публикация соберёт демонстрацию с виджетом.

Доступ «Все» означает, что писать в таблицу может любой, кто знает адрес. Для
обзора демонстрации это принятая цена: замечания не содержат ни денег, ни
персональных данных, а любая проверка личности заставила бы заказчика заводить
учётную запись ради одной строки. Если адрес начнут заливать мусором —
развернуть заново с новым адресом и поменять переменную; правка кода для этого
не нужна.

## Скрипт приёмника

```javascript
/**
 * Приём замечаний по демонстрации «Приёмки».
 *
 * Дописывает строку в лист «Замечания» той же книги, к которой привязан.
 * Лист и шапка создаются при первом сообщении: настраивать книгу руками не
 * нужно, и порядок столбцов задан здесь, а не соглашением.
 */
var ЛИСТ = 'Замечания';
var ШАПКА = ['Когда', 'Вид', 'Экран', 'Объект', 'Вкладка', 'Ширина', 'Имя', 'Текст'];

function doPost(запрос) {
  try {
    var данные = JSON.parse(запрос.postData.contents);
    var текст = String(данные.text || '').trim().slice(0, 4000);
    // Пустое замечание не пишется: строка «» в таблице — это работа
    // человеку, который будет гадать, что имелось в виду.
    if (текст.length < 5) return ответ({ ok: false, error: 'Замечание слишком короткое.' });

    лист().appendRow([
      new Date(),
      String(данные.kind || '').slice(0, 40),
      String(данные.section || '').slice(0, 80),
      String(данные.project || '').slice(0, 40),
      String(данные.tab || '').slice(0, 80),
      Number(данные.width) || 0,
      String(данные.author || '').slice(0, 120),
      текст,
    ]);
    return ответ({ ok: true });
  } catch (ошибка) {
    return ответ({ ok: false, error: String(ошибка).slice(0, 200) });
  }
}

function лист() {
  var книга = SpreadsheetApp.getActiveSpreadsheet();
  var найден = книга.getSheetByName(ЛИСТ);
  if (найден) return найден;
  var новый = книга.insertSheet(ЛИСТ);
  новый.appendRow(ШАПКА);
  новый.setFrozenRows(1);
  новый.setColumnWidth(8, 480);
  return новый;
}

function ответ(тело) {
  return ContentService.createTextOutput(JSON.stringify(тело))
    .setMimeType(ContentService.MimeType.JSON);
}
```

## Чем стережётся

`scripts/verify-demo.mjs` проходит путь целиком: открывает виджет, убеждается,
что пустое замечание отправить нельзя, пишет замечание, отправляет и сверяет то,
что дошло до приёмника, — текст, вид, экран и ширину окна. Приёмник при этом
подменён заглушкой в том же процессе, что раздаёт собранный каталог: проверка
стережёт форму и то, что она отправляет, а не работоспособность Google.

Собранная без `VITE_FEEDBACK_URL` демонстрация даёт именованное замечание, а не
молчание: страница без виджета — это страница без того, ради чего её отдавали.
