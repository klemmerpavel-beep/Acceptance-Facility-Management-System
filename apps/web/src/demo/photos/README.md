# Снимки объектов для демонстрации

Демонстрация на GitHub Pages работает без сервера: настоящие снимки приёмки
ей недоступны, а одна общая заглушка на все объекты превращает галерею
портфеля в повторение одной картинки.

## Что здесь лежит

**Сгенерированные изображения помещений**, по одному на объект наполнения.
Решение заказчика от 12.09.2026; созданы через Higgsfield, промпты запрещали
людей, текст, вывески и товарные знаки.

Это **не фотографии сданных объектов студии** и не портфолио. Объекты
демонстрации вымышлены целиком — коды, адреса, заказчики, суммы, — и
изображения к ним относятся так же: они показывают, как выглядит продукт с
картинками, а не что построила студия. Выдавать их за выполненные работы
нельзя ни в презентации, ни на сайте.

Прежняя редакция этого файла генерированные изображения запрещала — доводом,
что они выдадут себя за объекты, которых нет. Запрет снят решением заказчика;
взамен стоит запись выше, называющая файлы тем, что они есть.

**Сцена отвечает статусу объекта**, а не выбрана наугад: рядом с плиткой стоит
пилюля состояния, и «Готов» на фоне голого бетона спорил бы сам с собой.

| Файл | Статус объекта | Что на изображении |
|---|---|---|
| `R-27` | ждёт заказчика | работы приостановлены: стены оштукатурены, инструмент убран |
| `R-38` | новый | черновая коробка: бетон, стяжка, пыль |
| `R-42` | новый | старая комната до начала работ, обои содраны местами |
| `R-64` | в работе | штукатурные работы по маякам, часть стены — кирпич |
| `R-72` | в работе | монтаж кухни: корпуса собраны, фасадов ещё нет |

Объекты `R-19` (готов, офис), `R-31` (в работе, плитка) и `R-99` (в работе,
электрика и отопление) пока показывают векторные рисунки — их изображения
ожидаются.

## Как добавить изображение

Положите сюда файл и назовите его **кодом объекта**:

    R-19.jpg
    R-31.webp
    R-99.png

Годятся `.jpg`, `.jpeg`, `.png`, `.webp`, `.svg`. Сборка подхватывает каталог сама
(`import.meta.glob` в `../photos.ts`) — править код не нужно, достаточно
пересобрать демонстрацию.

**Рисунок-заглушку с тем же кодом удалите.** Два файла на один код дают в карте
соответствий две записи с одним ключом, и какая победит — решает порядок
обхода каталога, то есть случай.

Объект, для которого файла нет, получает фирменную подложку с кодом: она
выглядит подложкой и ничего не выдаёт за фотографию.

## Что сюда класть нельзя

Снимки эталона и любые чужие изображения. Только собственные материалы —
снятые или сгенерированные, — права на которые у студии есть.

## Вес и пропорция

Демонстрация целиком раздаётся статикой, и каждый мегабайт изображения — это
мегабайт загрузки у заказчика. Разумный предел на файл — 60 КБ.

Плитка показывает изображение в **3:2**, и приводить к ней нужно кадрированием
по центру, а не растягиванием: растянутое помещение читается как дефект
съёмки. Действующие файлы приведены к 800×533 px — двойная плотность для
плитки шириной около 400 px, больше экран не покажет. Пересчёт делается тем же
браузером, который уже стоит для проверок: новых зависимостей для этого не
требуется и вводить их нельзя.
